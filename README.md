# Rebuilt Documentation

Docusaurus documentation for Rebuilt by Difffuse Studio.

## Status

Initial site structure only. The full user guide, Rebuilt banner and annotated screenshots are still to be prepared and reviewed. The website has not been published.

## Local development

Use Node.js 22 LTS (Node 20 or later required).

```sh
npm ci
npm start
```

## Validation

```sh
npm run typecheck
npm run build
```

## Publishing later

The site is configured for `https://difffuse.github.io/rebuilt-documentation/`. Creating this repository does not publish the website. Configure GitHub Pages and its deployment workflow after the documentation has been reviewed.

## Design reference

Adapted from [Procedural Interiors Documentation](https://github.com/difffuse/procedural-interiors-documentation), commit `b4cc7ea1226a3f8e31bd444921ffe9ca369e4180`. Retains the Difffuse branding, Docusaurus configuration and shared theme styles. Rebuilt content is maintained separately.
