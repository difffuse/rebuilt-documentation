# Rebuilt 1.0

This guide documents the Rebuilt 1.0 feature set:

- Auto and Manual workflows for retopology, seams, UVs and baking.
- Editable seam generation and acceptance of existing UV layouts.
- Texture output controls for PNG, TIFF, OpenEXR and JPEG.
- Separate Unity, Unreal and Godot export destinations.
- Blender extension packaging for platform-specific installation.

Check your Superhive purchase page for the available downloads and release notes. This documentation does not replace the product's download page.
